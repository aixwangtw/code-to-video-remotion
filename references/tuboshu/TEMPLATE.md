# 第一節：長片規則（L1、L2）

## 1.1 片長與製作形式
- 8～11 分鐘【實測：L1 10:37、L2 9:15；頻道近期長片多為 8～10 分鐘，也有 13、16 分鐘】。
- 不出鏡【實測：L1、L2 影格皆無真人】。畫面全是「動畫圖解＋螢幕錄製＋網頁截圖」混合。
- L2 開場是一張手繪風熊角色插畫（情境短劇，兩隻熊對話，標題字樣在對話氣泡裡），再切到遊戲畫面。【實測】
  - 通用規則：開頭可用一個原創角色的插畫當情境，不需要真人。
- 底色因段落而異：L1 的事件段是深藍黑、遊戲類比段是淺灰白（卡片遊戲），L2 以深藍黑為主。沒有固定單一色，但每一段內只用一種底色。【實測】

## 1.2 結構時間軸（通用化）
L1 的章節（YouTube 章節實測，共 18 章，約 35 秒一章）：
事件 hook 0:00 → 名詞解釋 0:41 → 第一題概念 1:08 → 用「遊戲」重新包裝題目 1:28 → 方法一 2:11 → 方法二 2:45 → 規模對比（一億 vs 兩萬）3:25 → 回到「大廠還考不考」3:53 → 為什麼怕 4:26 → 我的三步驟 4:41 → 手動跑一遍 5:00 → 工具 5:49 → 實戰 6:09 → 笨方法 7:43 → 最佳解 8:13 → AI 怎麼用 8:36 → 結論 9:36 → 結尾 10:30。

規則：
1. 0:00～0:40：講一個具體事件或情境作 hook，結尾拋出「所以這件事到底該怎麼看」。
2. 緊接一個「名詞白話解釋」章（L1：什麼是刷題）。
3. 把抽象題目改寫成一個「遊戲」或日常類比，讓觀眾能自己玩（L1 的翻牌遊戲、L2 的卡丁車）。有計分板、計時或花費數字在畫面上即時更新。
4. 用兩個方法對照：先笨方法、再好方法，旁邊用數字（次數、花費）呈現差距。
5. 回扣標題問題，給 3 步驟流程。
6. 實戰示範用螢幕錄製。
7. 結尾：給一句立場結論加簡短收尾。
8. 章節很碎（約 30～60 秒一章），描述欄一定有章節時間戳與使用到的工具連結。

L2 的結構【實測影格】：小時候回憶 → 做出單機遊戲 → 「今天的路線」圖（兩張縮圖＋箭頭）→ 問題一（網路怎麼傳）→ 問題二（同步與判定）→ 每個問題用一個「錯誤畫面」開場（兩個螢幕看到的結果不一樣，問「誰說了算」）。
- 通用規則：用「畫面不一致」或「出錯」當每章的問題起點，再講原理。

## 1.3 開頭寫法
- L1：先講一個年份與人物事件，有後果（被退學、offer 沒了），20 秒內講完。
- L2：個人回憶加轉折（以前是小孩、現在能自己做遊戲），再丟任務。
- 共通規則：第一句不是主題名詞，是一個人或一件事；後果要在 20 秒內出現。

## 1.4 旁白語速與語氣
- L1 約 384 字／分、L2 約 373 字／分（whisper 逐字稿，說話時間內【實測】）；YouTube 自動字幕估 L1 約 383 字／分。
- 目標：370～390 字／分。比 Gary Chen 略慢。
- 語氣：口語，帶一點自嘲與玩笑（L2 的回憶梗）。句子短，一句 5～12 字。

## 1.5 字幕樣式【實測】
- 底部置中，白字、粗黑體；L1 約在畫面高度 90% 處，一行。
- 無底塊或極淡底，字級約畫面高度 4%。
- 畫面上方另有一條小標籤（例如事件主題、方法名），以圓點加小字呈現，每章換一次。【實測：L1 頂部有「● 標籤」】
- 重點句會另外用大字置中顯示（L1 的「如果 X 變成一個遊戲」整頁大字）。

## 1.6 運鏡與轉場【實測】
- 螢幕錄製段落有「放大到重點區域」的運鏡（例如放大題目、放大程式碼某幾行）。
- 圖解段落：卡片依序進場、旗子／箭頭移動、數字跳動。
- 轉場：硬切為主，偶爾淡出到黑底大字章名；沒有花俏轉場。
- 畫面左上、右上常有小資訊（花費、目前步驟），在畫面內即時變化。

## 1.7 縮圖【實測 1 張（L1）】
- 無人臉。淺灰底，左側放一個大圖示（本片為題庫網站 logo），右側三行粗黑體：「AI 時代」放在黑底圓角標籤內（白字）、「還要」黑字、「刷題？」橘色放大加手繪橘色底線，旁邊有放射短線。
- 字數：約 7 字，疑問句收尾。
- 配色：灰白底、黑、橘三色。

# 第二節：Shorts 規則（S1、S2、S3）

## 2.1 片長與格式
- 52～67 秒【實測：S1 52.6、S2 51.8、S3 67.5】。S1、S2 控制在約 52 秒。
- 直式 9:16，內容區塊滿版；若不是直式素材，上下留黑。
- 標題格式：「數字＋名詞＋ hashtag」或「問題＋解法名」【實測 S1、S2、S3 標題】。縮圖是直式字卡，見 2.7。

## 2.2 結構時間軸（秒）【實測，S1 為最典型】
S1（7 個清單）：
- 0:00～0:04 hook：一句提問式痛點（想做 X 又不知道裝什麼？），緊接承諾「七個一次講清楚」。
- 0:04～0:44 清單：7 項，每項約 5～6 秒。固定句型「第 N、名稱」加一句功能加一句效果。每項一個畫面切換，編號字樣出現在畫面中。
- 0:44～0:50 最後一項換節奏（「最後一個不太一樣」），做反差收尾。
- 0:50～0:53 行動呼籲：「快分享給身邊有這需求的朋友」。

S2（單一專案）：
- 0:00～0:05 hook：「最近有一個很紅的開源 X」＋名稱。
- 0:05～0:20 痛點與效果：先講問題，再講裝上後變化，再引用一則社群評價佐證。
- 0:20～0:45 規則清單：3 條，每條 5～8 秒，每條一個動畫圖示。
- 0:45～0:52 一句總結（它不是 A，而是 B），再用一句「值得試試」收尾。

S3（10 項清單）：
- 0:00～0:03 hook：「這 10 個 X 可以讓你的 Y 變好」，第二句「快點收藏」。
- 0:03～0:60 清單：每項 4～6 秒，每項先出編號加名稱，再講一句功能。

規則：
1. 前 3～5 秒必須包含「對象＋好處」，並明講「清單數量」或「單一專案名」。
2. 清單類：每項約 5 秒，固定三拍：編號名稱 → 它做什麼 → 一個具體效果或示範畫面。
3. 單一專案類：問題 → 效果 → 規則（最多 3 條）→ 一句翻轉的總結。
4. 結尾 3 秒內：行動呼籲（收藏或分享），不再補充新資訊。

## 2.3 開頭寫法（hook 句型，通用）
- 疑問式痛點：「想做 X 又不知道該用什麼？」
- 承諾式：「這 N 個 X，可以讓你的 Y 變好，快收藏」。
- 熱度式：「最近有一個很紅的開源 X」。
- 規則：不超過 15 字、第 1 句不放自我介紹。

## 2.4 旁白語氣與語速
- S1 約 433、S2 約 390、S3 約 425 字／分（whisper，含停頓整支平均）【實測】。
- 目標：390～430 字／分，比長片快。
- 句長 4～10 字，每句 1～2 秒；句與句之間幾乎不留空白（S1 的 33 句在 52 秒內）。
- 語氣：乾脆、直述、帶一點興奮，不加語助詞。

## 2.5 字幕樣式【實測 S1、S2、S3】
- 位置：畫面下方偏中（約 75～85% 高度），一行。
- S1、S3：字幕有黑色半透明圓角底塊，白字，粗黑體；編號項目（「第三、Pixel2Motion」）的字幕同樣在底塊內並稍放大。
- S2：白字、無底塊，在深色畫面上。
- 一句一換，沒有逐字高亮；關鍵詞用「畫面上方的大字標題」提示，不靠字幕上色。
- 畫面上方另有標題字（S2 用白字＋黃／綠／藍關鍵詞上色，例如「前面講一大堆，最後才說重點」中重點為黃）。

## 2.6 運鏡與轉場【實測】
- 畫面約每 2～3 秒變化一次（換圖、換卡片、元件進場），沒有長時間靜止畫面。
- 轉場：硬切加元件淡入。未見大幅度鏡頭推拉。
- 畫面類型：網頁截圖（專案 README、GitHub 頁）→ 示範成品（網頁動畫、天氣卡片、設計稿）→ 動畫圖解（箭頭、勾選、紅叉）。
- 每項工具都先給一個「專案頁截圖」當身分證，再給一個「產出畫面」當證據（S1、S3）。
- 配樂：未分析音訊，查不到結論。

## 2.7 縮圖【實測 S1、S2 兩張】
- 直式字卡，米白底。
- S1：兩層字，上層小黑字「讓 AI 幫你做動畫」，下層大字「7 個動畫 Skills」，其中「動畫」橘色，下方放一張工具介面插圖。
- S2：上方 GitHub 圖示＋專案名，中間大字「AI 輸出品質提升 10 倍」（「10 倍」橘色加黃色底線），下方兩個 hashtag 小標籤。
- 規則：2～3 層字，主標含數字，一個橘色強調詞，配一個圖示。縮圖也是米白底加黑橘，這與長片縮圖同色系。

# 第三節：長片與 Shorts 的差異、SOP 規則

| 項目 | 長片 | Shorts |
|---|---|---|
| 片長 | 8～11 分鐘 | 約 52 秒 |
| 語速 | 370～390 字／分 | 390～430 字／分 |
| 結構 | 事件 hook → 類比 → 對照 → 實戰 → 結論 | 痛點 → 清單或規則 → 行動呼籲 |
| 畫面變化 | 3～10 秒 | 2～3 秒 |
| 章節 | 一定有時間戳，約 35 秒一章 | 沒有 |
| 底色 | 深或淺，段落內一致 | 深色圖解、淺色截圖並存 |

SOP 規則：
1. 長片做「一個故事＋一個類比＋一個對照」，Shorts 做「一個清單或一條規則」。
2. 長片 hook 用事件或個人回憶，Shorts hook 用承諾或提問（含數字）。
3. 長片章節約每 35～60 秒換一個小題，描述欄放時間戳與工具連結。
4. 每一項工具或概念都配「證據畫面」：專案頁截圖加成果畫面。
5. Shorts 清單固定句型「第 N、名稱＋一句功能＋一句效果」，每項約 5 秒。
6. Shorts 結尾 3 秒內行動呼籲（收藏或分享）。
7. 字幕：底部、白字、粗黑體，可加黑半透明底塊；一句一換。
8. 縮圖：米白底、黑粗體加一個橘色強調詞、含數字或疑問句、配圖示；長片可無臉。
9. 標題：Shorts 為「數字＋名詞」加 2～3 個 hashtag；長片為疑問句（含年份或時代詞）。
