# 拍片共用規則（模式 A／B 都適用）

## 輸出路徑與檔名

- **正式版影片、縮圖、字幕檔先輸出到 Remotion 專案，再備份到 Windows 下載資料夾**：主要位置 `~/projects/Remotion/output/<影片名>/`（`output/*` 已被 gitignore，不進版控）；備份 `C:\Users\js098\Downloads`（WSL 路徑 `/mnt/c/Users/js098/Downloads`）。兩處用同一支交付腳本一起寫入並用 md5 驗證一致。檔名照 Remotion `tutorial-publish-pipeline` §2 慣例：`<影片名>-<平台>-<解析度>-<長寬比>-<格式大寫>.<副檔名>`（例：`xxx-IG-1080x1920-9x16-MP4.mp4`、`xxx-cover-1080x1920-9x16-JPG.jpg`）；暫存工作區（`/tmp`）只放中間檔。

## 封面第 0 格

- **第 0 格要是封面**（使用者 2026-10-24：傳到 LINE 會拿第一格當縮圖，空白就看不出是什麼）：片頭放 1.5 秒封面（主角／主視覺加標題），第 0 格不可淡入、不可空白，之後硬切進第一場。0.5 秒實測不夠，LINE 抓到的是封面之後的畫面。輸出時用 ffmpeg 把封面 JPG 內嵌成縮圖（`-c:v:1 copy -disposition:v:1 attached_pic`，不要加 `-shortest`），第 0 格設為關鍵影格，並加 `-movflags +faststart`。輸出後抽 0、0.5、1.0、1.4 秒四格，確認都是封面。封面另外存一張 `<影片名>-cover-<解析度>-<長寬比>-JPG.jpg`。

## 版面留白與安全區（沿用 Remotion 專案慣例，影片與縮圖都適用）

數值出處：`~/projects/Remotion/AGENTS.md`「直式短影音的安全帶位」、`src/thumbnails/ThumbnailReel.tsx`、`src/thumbnails/FeatureChips.tsx`。

- **直式 1080×1920 安全帶位**：標題帶 top 16.8%（高 11%）；視覺帶 inset `16.8% 8% 25.2%`；字幕帶 top 76.8%（高 11%）；左右安全區各 8%。實測內容落在約 17.7%–79.5%。不要用 10%／70% 舊值。
- **直式縮圖**：外框 padding 70、上 220、下 260；內容垂直分布、水平置中；字級參考主標 132、副標 72、標籤 46（文字多的案例卡可等比縮小）。
- **膠囊／標籤**：`borderRadius: 999`、邊框 `max(3, 字級×0.08)`、內距約「字級×0.35／字級×0.7」、白底，只用一個強調色。
- **留白原則**：四周外距一致且充足；標題、卡片、標示之間的間距統一；整塊內容在安全區內垂直置中，不留一大塊空白、也不貼邊。完成後渲染一格，量實際內容佔的百分比驗證，不要只看程式碼。
- 橫式 16:9（1920×1080）目前沒有定案的安全帶位數值，先比照左右 8%、上下各留約 10%，並在交件時說明這是暫定值。

## TTS 發音替換

主表在 `.claude/skills/tutorial-voiceover-style/SKILL.md` §3。以下是全域拍片 skill 另外累積、尚未併入主表的詞（發音替換只改念稿、不改字幕；新詞先做小樣試聽再整份重產）：

- **發音替換只改念稿、不改字幕**：詳解→祥解、確認→確刃、卷→倦、按鈕→按扭、Word→Word 檔、I 人→哀人、隔閡→隔合、續攤→續貪、樂意→樂義、出謀→出牟、搭訕→搭善、真君子→珍君子、贏了→營了、數位游牧→數位由木、雙方→霜方、陸陸續續→路路續續、不同國家→不同幗家、一桌→一捉（2026-10-24 越南短片，eleven_v3 本人聲音實測念錯後由使用者指定）（完整表見 Remotion `tutorial-voiceover-style` §3）。新詞先做小樣試聽再整份重產。
